# Ads: where they come from

Every picture in this folder (atlas.webp, the ct-, pc-, band-, roof-, screen-, pole- and sticker- pictures, and icons/)
was made for this game by `src/world/scenery/ads/make_ads.py` (Pillow), from the text in `src/world/scenery/ads/ads.json`.
Rerun that script to remake them. `atlas.json` and `index.json` list what is where.

| What | Source | License |
|---|---|---|
| Made-up ads, slogans, shop signs, posters, road-safety notices | written and drawn for this game | the game's own |
| Cool tools program names, colors and icons (`icons/`) | Jon's own Cool tools app kit (`app-kit/icons`, `app-kit/programs.json`) | Jon's own |
| Lettering | drawn with the Windows fonts Segoe UI, Impact, Bahnschrift and Georgia | only pictures of the letters ship, never the font files |

No photographs or outside artwork are used.
